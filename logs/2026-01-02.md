# Development Log - 2026-01-02

## Session 1: WebSocket Real-time Updates

### Features Implemented

#### WebSocket Integration with Laravel Reverb
- Added `web_socket_channel` package for WebSocket connections
- Created `WebSocketService` (`lib/core/services/websocket_service.dart`)
  - Implements Pusher/Reverb protocol
  - Subscribes to `cameras` channel
  - Listens for `.image.updated` events
  - Auto-reconnect with exponential backoff (max 5 attempts)
  - Ping/pong keepalive every 30 seconds
- Created `webSocketServiceProvider` and `webSocketConnectionProvider`
- Integrated with `CamerasNotifier` to update individual camera images in real-time

#### App Lifecycle Management
- Changed `VesteraalenTimelapseApp` from `ConsumerWidget` to `ConsumerStatefulWidget`
- Added `WidgetsBindingObserver` mixin
- On app resume: reconnects WebSocket, resumes polling, fetches fresh data
- On app pause: stops polling (WebSocket stays connected)

#### Silent Image Updates
- Removed loading indicator during background refreshes
- Updated `CachedNetworkImage` with zero fade durations for instant transitions
- Empty placeholder (no spinner) for seamless image swaps

#### WebSocket Status Indicator
- Added WebSocket connection tile to Settings page
- Shows: Connected (green), Disconnected (red), Disabled (grey)
- Displays status text: "Connected", "Disconnected", "Connecting...", "Disabled"

### CI/CD Fixes

#### Android Deploy Trigger
- **Bug**: Android deploy only triggered on git tags (`v*`), not on push to main
- **Fix**: Changed trigger from `tags: ['v*']` to `branches: [main]`

#### WebSocket Environment Variables
- Added to both `ios-deploy.yml` and `android-deploy.yml`:
  - `WEBSOCKET_ENABLED=true`
  - `REVERB_HOST=nesthus.no`
  - `REVERB_PORT=8080`
  - `REVERB_SCHEME=https`
  - `REVERB_APP_KEY` (from GitHub secrets)

#### iOS App Store Encryption
- Added `ITSAppUsesNonExemptEncryption = false` to `Info.plist`
- Prevents Apple from asking encryption compliance questions on each submission

### Environment Configuration

Added to `EnvConfig`:
- `webSocketEnabled` - Whether WebSocket is enabled
- `reverbHost` - Reverb server hostname
- `reverbPort` - Reverb server port
- `reverbScheme` - http or https
- `reverbAppKey` - Reverb app key
- `webSocketUrl` - Computed full WebSocket URL
