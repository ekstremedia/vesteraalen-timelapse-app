## Architecture Decisions

### State Management: Riverpod
Chose Riverpod (NotifierProvider pattern):
- Type-safe
- Testable
- Supports async operations
- No BuildContext required for accessing state

### Theming: Material Design 3
Using Material Design 3 with dark/light mode:
- Dark theme optimized for image viewing
- Teal primary color (`#4DB6AC`) matching ekstremedia.no
- Google Fonts for typography

### Localization: Manual i18n
Following huske-mobile pattern with manual `AppLocalizations`:
- Norwegian Bokmål (nb)
- Norwegian Nynorsk (nn)
- English (en)

### Caching Strategy
In-memory cache with TTL:
| Data | Duration | Reason |
|------|----------|--------|
| Cameras list | 30 seconds | Current images update frequently |
| Today's timelapse | 30 seconds | May still be processing |
| Historical timelapse | 5 minutes | Won't change |
| Available dates | 1 hour | Changes once daily |

### Responsive Design
Camera grid adapts to screen width:
| Width | Columns |
|-------|---------|
| < 600px | 1 |
| 600-899px | 2 |
| 900-1199px | 3 |
| >= 1200px | 4 |

## Phase 8: CI/CD Setup (COMPLETED)

**Workflows Created:**

1. `.github/workflows/flutter.yml`
   - Runs on push/PR to main/develop
   - Analyzes code
   - Runs tests
   - Checks formatting
   - Builds debug APK and iOS

2. `.github/workflows/android-deploy.yml`
   - Triggered on version tags or manual dispatch
   - Builds release APK and App Bundle
   - Uploads to Firebase App Distribution
   - Auto-increments build number from GitHub run number

3. `.github/workflows/ios-deploy.yml`
   - Triggered on version tags or manual dispatch
   - Builds release IPA
   - Uploads to TestFlight
   - Auto-increments build number from GitHub run number

**Required GitHub Secrets:**
- `API_BASE_URL` - API base URL
- `FIREBASE_APP_ID_ANDROID` - Firebase app ID
- `FIREBASE_SERVICE_ACCOUNT` - Firebase service account JSON
- `ANDROID_KEYSTORE_BASE64` - Base64 encoded keystore
- `ANDROID_KEYSTORE_PASSWORD` - Keystore password
- `ANDROID_KEY_PASSWORD` - Key password
- `ANDROID_KEY_ALIAS` - Key alias
- `IOS_CERTIFICATE_BASE64` - Base64 encoded p12 certificate
- `IOS_CERTIFICATE_PASSWORD` - Certificate password
- `IOS_PROVISIONING_PROFILE_BASE64` - Base64 encoded provisioning profile
- `IOS_CODE_SIGN_IDENTITY` - Code sign identity
- `IOS_PROVISIONING_PROFILE_NAME` - Provisioning profile name
- `IOS_TEAM_ID` - Apple Developer team ID
- `APP_STORE_CONNECT_ISSUER_ID` - App Store Connect issuer ID
- `APP_STORE_CONNECT_KEY_ID` - App Store Connect key ID
- `APP_STORE_CONNECT_PRIVATE_KEY` - App Store Connect private key
