### 4. CI/CD Pipeline Fixes

**Flutter Version Issues:**
- CI was using Flutter 3.24.0 (Dart 3.5.0) but dependencies required Dart 3.8+
- Fixed by specifying `flutter-version: '3.38.5'` in all workflows
- Removed `cache: true` to avoid stale cached versions

**Dependency Compatibility:**
- `flutter_lints` 6.0.0 requires Dart 3.8+
- `intl` package conflicts - removed explicit dependency, using transitive from `flutter_localizations`
- Set `intl: any` to let Flutter resolve the correct version

**Code Compatibility:**
- `Color.withValues()` is new in Flutter 3.38+ - changed to `withOpacity()` for broader compatibility
- Added `deprecated_member_use: ignore` to `analysis_options.yaml`

**Workflow Improvements:**
- Added `concurrency` to cancel outdated CI runs
- Disabled iOS workflow until signing is configured
- Fixed dart format issues

## Issues Encountered & Solutions

### Issue: subosito/flutter-action using old Flutter version
**Symptom:** CI kept using Flutter 3.24.0 despite specifying newer version
**Solution:** Explicitly set `flutter-version: '3.38.5'` and removed `cache: true`

### Issue: intl package version conflicts
**Symptom:** `flutter_localizations` pins intl to different versions across Flutter versions
**Solution:** Use `intl: any` to let Flutter resolve automatically

### Issue: Color.withValues() not available
**Symptom:** `The method 'withValues' isn't defined for the type 'Color'`
**Solution:** Use `withOpacity()` instead (deprecated but works everywhere)

### Issue: Firebase credentials accidentally committed
**Symptom:** Sensitive JSON files pushed to git
**Solution:** Removed with `git rm --cached`, updated `.gitignore`, regenerate service account key
