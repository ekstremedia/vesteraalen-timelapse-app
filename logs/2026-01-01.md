## Issues Encountered & Solutions

### Issue: subosito/flutter-action using old Flutter version
**Symptom:** CI kept using Flutter 3.24.0 despite specifying newer version
**Solution:** Explicitly set `flutter-version: '3.38.5'` and removed `cache: true`

### Issue: intl package version conflicts
**Symptom:** `flutter_localizations` pins intl to different versions across Flutter versions
**Solution:** Use `intl: any` to let Flutter resolve automatically

### Issue: Color.withValues() not available
**Symptom:** `The method 'withValues' isn't defined for the type 'Color'`
**Solution:** Use `withOpacity()` instead (deprecated but works everywhere)

### Issue: Firebase credentials accidentally committed
**Symptom:** Sensitive JSON files pushed to git
**Solution:** Removed with `git rm --cached`, updated `.gitignore`, regenerate service account key

### iOS GitHub Actions Workflow

Created/updated `.github/workflows/ios-deploy.yml`:

**Workflow Steps:**
1. Checkout code
2. Setup Flutter 3.38.5
3. Get dependencies
4. Create .env file
5. Install Apple Certificate (via `apple-actions/import-codesign-certs@v2`)
6. Install Provisioning Profile (base64 decode to `~/Library/MobileDevice/Provisioning Profiles/`)
7. Increment build number
8. Build iOS (`flutter build ios --release --no-codesign`)
9. Archive without signing (`CODE_SIGNING_REQUIRED=NO`)
10. Export IPA with signing via `ExportOptions.plist`
11. Upload to TestFlight (`apple-actions/upload-testflight-build@v1`)
12. Upload IPA as artifact

**Key Files Created:**
- `ios/ExportOptions.plist` - Signing configuration for App Store export
- `certificates/` folder (gitignored) - Local certificate storage

### Issues Encountered & Solutions

| Issue | Solution |
|-------|----------|
| `akiojin/install-provisioning-profile-github-action@v1` not found | Replaced with manual base64 decode |
| Base64 decode error | Use `echo -n` with env variable instead of direct secret interpolation |
| Provisioning profile applied to Pods | Build with `CODE_SIGNING_REQUIRED=NO`, sign during export |
| `app-store-connect` export method requires auth | Changed to `app-store` method, separate upload step |
| IPA not found at `Runner.ipa` | Added dynamic IPA path finding |
